## ⚡ 30 秒快速導覽 (Project Overview)

**IP CrossLab** 是一個專為創作者、編劇、獨立遊戲團隊與影視企劃打造的 **AI 跨媒體 IP 孵化引擎**。

在過去，一個好故事要跨足遊戲、電影、條漫或周邊商品，往往需要跨領域顧問動輒數月的跨界評估；而大部分創作者因缺乏跨媒體視角，78% 的 IP 改編在後期面臨「水土不服」甚至爛尾。

**IP CrossLab 讓你在 10 秒內：**
1. **輸入題材**（例如：「宮本武藏 × 五輪書 × 日本妖怪」、「賽博龐克九份老街」）
2. **AI 全自動多維拆解**：即刻產出 5 大媒體（🎮 遊戲、🎬 電影、📺 YouTube、📖 小說條漫、🧸 商業潮玩）的工業級企劃白皮書。
3. **產出 IP 跨媒體機會評分（Opportunity Score）** 與 **三階段甘特圖發行 Roadmap**。

---

## 💥 產業痛點 (The Problem)

- **單一媒介局限**：創作者通常擅長小說或劇本，但對「遊戲核心戰鬥循環」或「YouTube 點擊率 Hook」毫無概念。
- **改編各行其是**：影視部門與遊戲部門後期各自為政，世界觀矛盾，宣發資源衝突互咬。
- **提案成本極高**：向投資人或發行商 Pitch 跨媒體概念前，需耗費數十萬資金與數週時間整理各類企劃書。

---

## 💡 解決方案 (The Solution)

IP CrossLab 扮演創作者的「虛擬好萊塢跨媒體智囊團」：
- **同構矩陣架構**：從同一個世界觀核心，平行生成 5 個符合各自媒介規格的專屬企劃案。
- **好萊塢與 3A 工業標準**：不是泛泛的聊句劇情，而是精準給予 **Logline、三幕劇抗衡、核心循環機制、CTR 封面設計與商業授權品類**。
- **零門檻操作**：無需註冊、無需登入、即開即用，手機與桌面端均提供優雅沈浸的手機 App 模擬體驗。

## 🚀 核心功能 (Features)

### 1. 5 棲跨媒體深度企劃 (5-Pillar Transmedia Pitch)
- 🎮 **遊戲 (Game)**：核心遊戲類型 (Action RPG/Soulslike)、核心戰鬥循環 (Core Loop)、核心玩法機制、美術風格、Steam/PS5 平台發行建議。
- 🎬 **電影／影集 (Movie/Series)**：好萊塢式 Logline、主角弧光 (Arc)、三幕劇節奏結構（起承轉合）、預告片標誌性定格鏡頭。
- 📺 **YouTube／短影音 (YouTube/Social)**：冷啟動前 15 秒鉤子 (Hook)、爆款縮圖大字標題與文案、第一季 5 支連載腳本大綱。
- 📖 **小說／條漫 (Novel/Webtoon)**：連載黃金 3 話大綱、高黏著世界觀設定、伏筆與世界觀厚度。
- 🧸 **商業化與潮玩 (Commercial/Merchandise)**：一番賞盲盒公仔、品牌跨界聯名、快閃店與防禦性長青授權生態。

### 2. IP 綜合潛力雷達評分 (IP Opportunity Score)
以五維量化模型，評估 IP 在不同媒介的適配度與商業潛力：
- 核心創意獨特性
- 跨媒體拓展指數
- 泛娛樂破圈係數
- 長線衍生品變現力
- 粉絲黏著沉澱度

### 3. IP 孵化發行路線圖 (Transmedia Roadmap)
自動生成 **Phase I (種子累積) ➔ Phase II (破圈擴散) ➔ Phase III (全媒介變現)** 的最佳時序建議。

### 4. 黑客松評審 3 分鐘速覽導覽 (Judge Tour)
專為競賽評審設計的步驟指引，在 180 秒內看懂商業價值、技術核心與跨媒體全貌。

## 🛠️ 技術架構 (Tech Stack)

```
┌────────────────────────────────────────────────────────┐
│               Frontend (React 19 + Vite)               │
│  - Tailwind CSS v4 Modern Glassmorphism Styling        │
│  - Lucide React Iconography                            │
│  - Mobile App Simulator & Responsive Layout            │
└───────────────────────────┬────────────────────────────┘
                            │ REST /api/analyze-ip
┌───────────────────────────▼────────────────────────────┐
│             Backend Service (Express + Node.js)        │
│  - Google GenAI SDK (@google/genai)                    │
│  - Gemini 3.8 Flash Engine (Structured JSON Output)    │
│  - Fallback / Offline Curated Engine (High-Availability)│
└────────────────────────────────────────────────────────┘
```

- **Frontend**：React 19, TypeScript, Tailwind CSS v4, Motion, Lucide Icons
- **Backend**：Express, Node.js, tsx
- **AI Core**：Google Gemini 3.8 Flash (`gemini-3.8-flash`) 結構化 JSON 輸出
- **安全性**：Gemini API Key 採 Server-side 環境變數保護，前端絕無密鑰洩漏風險；無 API Key 時無縫切換至本地高擬真示範引擎。

## 💻 本地開發 (Local Setup)

```bash
# 1. 複製專案
git clone https://github.com/your-username/ip-crosslab.git
cd ip-crosslab

# 2. 安裝依賴
npm install

# 3. 設定環境變數 (選用，無金鑰亦可使用完整 Demo 模式)
cp .env.example .env
# 在 .env 填入您的 GEMINI_API_KEY

# 4. 啟動本機開發伺服器
npm run dev

# 5. 開啟瀏覽器訪問
http://localhost:3000
```
